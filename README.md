# Motion Lab v0.5 — Curated Collection

A complete Next.js + React Three Fiber gallery of **10 live particle artworks**.

## Changes since v0.4.1
- Removed Fireworks and Aurora from the project and gallery.
- Replaced Dream Butterfly with a monarch-inspired orange-and-black butterfly featuring wing markings.
- Reworked Blooming Flower as Twin Blossoms: rose and violet flowers with stems.
- Added Particle Fountain: moving points follow water trajectories using a dynamic position buffer.
- Added Birthday Cake: two cake tiers, icing, candles, flames, and confetti.
- Kept the small particle style, default Glow Off, and existing artwork viewer controls.

## Install on Windows

```powershell
cd "C:\coding file\personal_web\motion-lab"
npm.cmd install
npm.cmd run dev
```

Copy the **contents** of `motion-lab-v0.5` to your existing `motion-lab` folder, replacing same-name files. Preserve `.git`. After verifying, remove the old `scenes/Fireworks.tsx`, `scenes/Aurora.tsx`, and their `public/source/` copies if they remain from an earlier version. They are not used by v0.5.

Build: `npm.cmd run build`. Commit: `git add -A; git commit -m "Motion Lab v0.5 - Curated Collection"; git push origin main`.

## Notes
- All scene assets are generated by code; there are no external art files.
- Motion Lab's artist-rendered visuals depend on the GPU/browser. Review the four updated pieces visually on your machine.
- The fountain updates one GPU position buffer every animation frame; on older devices you may want to reduce COUNT in `scenes/Fountain.tsx`.
